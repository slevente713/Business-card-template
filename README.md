# Business card template

Ez a HTML fájl arra jó hogy beleírod a fiókjaid linkjeit, és lesz egy online névjegykártyád. This HTML file is designed for you to enter the links to your accounts, creating a digital business card.

## Hogyan használd? How to use?

Keresd meg az <a href> részt, és ott eggyértelműen le van írva, mit kell csinálni. Look for the <a href> section, and there, you can see what to do from my comments.
